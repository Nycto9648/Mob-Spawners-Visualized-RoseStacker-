# In This Pack

This resource pack adds icons to every mob spawner so players on servers can easily identify spawners. This resource pack specifically plugs into the popular RoseStacker plugin to work on many servers. It also fixes spawner block models to be more consistent with regular blocks and edits the spawner texture to have a small window for viewing the mob inside.

# 📥 Required Plugin

This pack requires **RoseStacker** to display mob icons on supported servers.
